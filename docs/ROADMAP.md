# Operational roadmap (Paseo heartbeat queue)

This file is the working queue for the automated build loop, which runs as two Paseo heartbeats on agent `7df45c0` (claude-haiku-5-5, per `paseo agent inspect`): a **builder** heartbeat (`0b1cde69`, cron `0 * * * *`, Europe/Madrid) picks the top "Ready to build" item and ships, commits (never pushes), screenshots and shares a Cloudflare tunnel every hour; a **supervisor** heartbeat (`bc87feb0`, cron `30 */6 * * *`) reviews the unpushed work, verifies the tests, unblocks anything blocked by making a recorded decision, pushes, publishes the Pages link and changelog, researches other embroidery software (Wilcom, Ink/Stitch and friends) and refreshes this queue. Each firing is stateless and re-reads this file from scratch; that's by design. The earlier arrangement (a `paseo schedule` starting a fresh Haiku agent each hour, id `44e95934`) is gone — self-registered heartbeats work now. Strategic scope and decisions still live in `docs/PLAN.md`; detailed build history lives in `docs/IMPLEMENTATION_STATUS.md`. This file only tracks what to build next and what just shipped.

Rules for the builder: always take the top item in "Ready to build" you haven't finished. If it's ambiguous or too big for one hour, scope a complete, tested slice of it yourself — do not wait for a decision. **Keep looping within the hour**: after shipping one item, check your elapsed time, and if you're comfortably under budget (rule of thumb: well under 40-45 minutes used), go pick up the next item instead of stopping. The first three hourly runs each finished in 4-11 minutes and still stopped at one item — that is under-using the budget, not a success condition. Never leave a heartbeat with nothing shipped. If the queue is empty, pull the next concrete item from `docs/PLAN.md`'s open work yourself, add it here, and build it.

Rules for the supervisor: verify tests actually pass and diffs match commit messages before moving an item to "Done this cycle". Keep at least 4 concrete, unambiguous items queued at all times. Push to `origin/main` only once verified.
