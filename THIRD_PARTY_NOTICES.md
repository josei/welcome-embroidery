## Ink/Stitch pystitch JEF/VP3 reader reference (MIT)

`src/readers.js` is an independently written JavaScript port for bounded JEF and VP3 stitch decoding; it does not bundle the upstream Python reader modules. Its behavior follows the Ink/Stitch pystitch readers pinned at commit `b72b557f2ebb1fdc51f30edc3c73ff6a851ea015`. The corresponding MIT license text is included in `LICENSE-THIRD-PARTY-pystitch.txt`. `node test/readers.test.js` passes all 4 tests, including parity against all 43 corrected-oracle corpus fixtures and synthetic JEF STOP plus VP3 `(0,0)` origin/no-op jump cases and raw-versus-corrected VP3 digest details. Upstream: <https://github.com/inkstitch/pystitch/tree/b72b557f2ebb1fdc51f30edc3c73ff6a851ea015>.

## Ink/Stitch embroidery font source: Néon blinking (SIL OFL 1.1)

Source project: <https://github.com/inkstitch/embroidery-fonts/tree/c7e3a05c3d6f5c77b881c50f257851af9a8e9cb8/src/neon_blinking>, pinned at `c7e3a05c3d6f5c77b881c50f257851af9a8e9cb8`. The upstream `LICENSE`, `font.json`, `ltr.svg`, and preview are included under `fonts/neon_blinking/`; the license identifies this Ink/Stitch adaptation as OFL 1.1 and its Sportrop source/copyright.

`glyphs.json` is a deterministic subset generated by `python3 scripts/extract-neon-font.py`. It retains the authored path geometry, glyph advances, scale limits, and per-path `stroke_method`, `bean_stitch_repeats`, and `running_stitch_length_mm` source metadata. The editor exposes the **plain-running-centerline** variant for uppercase A–Z, digits, space, period, comma, exclamation, question mark, and hyphen. It flattens cubic curves, uses the authored centerline and advances, and samples sewing runs at Welcome's 2.5 mm maximum. It deliberately does not reproduce Ink/Stitch's bean-stitch repeats or variable per-font stitch-length behavior. This is a supported reduced running-stitch interpretation, not a claim of full Néon blinking or Ink/Stitch reproduction. Supported nominal font size is 20–60 mm, corresponding to upstream 0.5–1.5 scale limits. The original small Welcome Mono remains the default font.

The embroidery-font source and modified/subset form remain under the OFL included with the font. The application is MIT-licensed (see LICENSE). Application compiler/serializer code is original JavaScript, informed by pinned pystitch behavior, not a direct source translation.

The OFL requires that modified versions do not use a Reserved Font Name; the files are renamed data conversions and carry the original family name as attribution only.
