# Validation fixtures

`embroidepy/samples.zip` is the original archive of the MIT-licensed [EmbroidePy/samples](https://github.com/EmbroidePy/samples) repository at commit `6e65f1ae8599b1e04d3e082aae1b86abed52ec9e`.

- [Manifest](embroidepy/manifest.json): pinned origin, archive SHA-256, extension counts, original file URLs and individual SHA-256 hashes.
- [License](embroidepy/LICENSE): original upstream notice, also present in the ZIP.

The 627 archived files include previews, sidecars and documentation, not 627 independent designs. Most are exports of five design families. The files have been downloaded and hashed; Welcome has not yet parsed or validated their embroidery contents. Keep fixture assets separate from application runtime assets.
